# Code of Conduct

## Our Pledge

We want this project to be a respectful, inclusive, and constructive place for learning and collaboration. Everyone who participates is expected to help create an environment where people can contribute without fear of harassment or discrimination.

## Expected Behavior

- Be respectful and professional in discussions, reviews, and issue reports.
- Assume good intent while remaining open to correction.
- Give specific, constructive feedback about code and ideas.
- Respect different levels of experience, backgrounds, identities, and viewpoints.
- Protect private information, credentials, and sensitive organizational data.
- Focus on what is best for the project and its learning objectives.

## Unacceptable Behavior

- Harassment, discrimination, threats, intimidation, or personal attacks.
- Sexualized language or unwanted sexual attention.
- Publishing private information or credentials without permission.
- Trolling, deliberate disruption, or abusive communication.
- Uploading raw private messages or confidential organizational data.
- Any conduct that would be inappropriate in a professional classroom or workplace.

## Reporting Concerns

Report unacceptable behavior privately to the project maintainer through the contact method listed in the repository or course project instructions. Please include what happened, where it happened, and any relevant links or evidence. Reports will be handled as confidentially as practical.

## Enforcement

Project maintainers may remove comments, reject contributions, or restrict participation when behavior violates this code. Decisions will be made with the safety and dignity of participants in mind.

## Scope

This code applies in project spaces, issue trackers, pull requests, code reviews, and other public or private spaces where someone is representing the project.
